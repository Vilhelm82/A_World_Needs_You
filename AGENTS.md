# Repository instructions

For Worldkeeper play, read `CLAUDE.md` and follow its routing instructions. It
loads the preserved base harness and, when selected, the courtroom module.
All harness-relative paths refer to the repository root.

For a code/editing task, do not start roleplay. Do not read existing sealed
worlds or session records unless the task explicitly requires them. Run the
courtroom controller tests with `python3 -m unittest discover -s tests -v`.
The courtroom starter cases are spoilers, not test reports. Avoid printing them.

For new court play, require the witness foundation checks and authoring review in
`modules/courtroom-v2/authoring.md`. The historical Last Light and Second Signature
examples are not ready for play. Do not backfill facts in a committed world.
Missing authored knowledge is an engine fault, never witness evasiveness or an
adverse credibility cue. Relay character contributions without inventing tells.

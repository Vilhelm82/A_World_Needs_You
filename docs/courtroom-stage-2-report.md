# Stage 2 report — witness grounding contract

Implementation verified: **240 deterministic tests run, 240 passed** at the Stage 2
boundary. This report was written retrospectively after the requested reporting
order was missed; it does not claim it was delivered before Stage 3.

- Removed permission to invent historical colour. Phrasing and manner may vary;
  qualifications, clothing, relationships, habits and physical actions may not be
  improvised. Absence of a field is never evidence of personal absence.
- Adopted never knew, cannot recall, approximate recall, committed withholding,
  and never authored. Only never authored is a gap.
- Each declared uncertainty boundary carries a witness owner, kind, topic/scope
  and fixed account. The controller validates ownership/existence. Responses may
  cite these boundaries in sealed grounding metadata, not public speech.
- The pause says the simulation could not ground an answer. It does not label the
  fact material, invent testimony or portray hesitation/evasion. Its event goes
  only to the player.
- Updated the OpenCode response contract and authoring/session documentation.

Tests cover a boundary assigned to another witness, a nonexistent claimed boundary,
and preservation of valid owned metadata in sealed audit only. Existing routing,
restart, transcript, jury and backend tests remained passing.

Limits: field/reference checks do not prove that arbitrary prose follows from a
boundary. Later semantic grounding checks address that imperfectly. The player can
observe a technical pause; the resulting meta-signal is accepted, not concealed.

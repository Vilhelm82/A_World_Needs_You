# Authoring V2 implementation report

The schema proposal and validator plan were delivered before implementation.

Implemented shared space/time/records/flows, computed per-identity envelopes,
owned perception limits, seven module-owned witness templates, routine/episode
layers, explained account divergences, fairness checks and sealed issue anchors.
Record receipt does not disclose hidden provenance or alterations. Every V2 witness
answer requires an owned citation; invalid answers pause before becoming testimony.

The coverage gate now requires blind probes in every template family, informed
follow-ups against visible routine/substrate sources, deterministic citation checks,
and an author-review flag below three ordinary-answer source layers. Existing
thresholds, independent graders, third-grader majority, split defects, sealed digests
and the nonplaying-human exception remain. The report contract is coverage-v4.

Amendments support all four substrate layers, derive checker scope from shared
entries, preserve original commitment bytes, reproject identities and rebuild changed
sessions independently. Witness patches cannot add freehand knowledge. Account
changes must be bound to the amended entry. Whole-set rejection and fresh independent
candidate authors remain mandatory. Historical scalar facts cannot be overwritten.

Validation: **320 tests passed**, including the complete deterministic suite and
new canaries, mandatory citations, fairness, per-family coverage, linked amendment
replay and restart. No external model was used by the tests. The adapter tests use
an explicit fake transport, not a claim of live provider success. Full diff checked;
34 protected historical-case files remain byte-identical.

**Live rehearsal was skipped at the user's explicit request.** Per-family live
counts, post-tiebreak invention totals and split counts are therefore not measured.
No case is offered for play without a passing real rehearsal. Structural validation
alone does not prove semantic coherence or complete witness coverage.

Historical findings remain unchanged: the earlier small Grok check answered three
covered ordinary questions without a gap and returned one gap on a deliberately
missing exact-time probe. The old fresh-draft single-grader exercise had 63 ordinary
answers: 44 grounded, 14 authored uncertainty, zero gaps and **five inventions**;
its six deliberate probes produced six gaps. Those are failed historical results,
not a V2 rehearsal or revised-grader result.

A pause or grounding-check result remains an unavoidable player meta-signal.
Referees/graders are fallible. Shared source structure and owned references enforce
application boundaries, not semantic omniscience; provider infrastructure may still
be shared outside the program's control.

with owner-only permissions, outside the commit. The author received only the
specification/schema, public procedural configuration and existing public setting.
